# 07_WRITING

Drafts that may become public or professional expression.

Possible forms:

- Articles
- Xiaohongshu posts
- Portfolio viewpoints
- Talks
- Interview language

Writing should grow from the knowledge base. It should not become a separate parallel opinion system.

## Agent Questions

- Which Insight, Principle, Method, or Working Thesis does this writing grow from?
- Is this ready to write, or still a thought that belongs elsewhere?
- Does the draft need evidence from Cases, Sources, or Project Learnings?
- Is the expression faithful to Harper's current judgment?

Harper can still paste rough writing here, but Agent should keep it connected to the knowledge system.
