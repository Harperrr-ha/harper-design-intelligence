# 05_WORKING_THESES

Long-term unresolved questions.

Use this folder when the question matters but the conclusion is not stable yet.

Examples:

- 设计如何真正产生商业价值？
- 品牌识别到底来自哪里？
- 产品差异化应该从哪里产生？
- 设计策略和审美判断的边界是什么？

Each Thesis should include:

- Current Position
- Questions
- Supporting Evidence
- Counter Evidence
- Cases
- Project Experience
- Changed My Mind
- Next Question

Use `templates/thesis-template.md` for new theses.
