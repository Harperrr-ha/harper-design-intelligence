# Harper Personal IP Positioning

> Status: WORKING THESIS  
> First developed: 2026-08-17  
> Updated: 2026-08-19

## Core Question

Harper 的个人 IP 到底应该建立在什么上，才能同时保留专业性、个人感和长期价值，而不是变成普通的设计知识号、职场号或生活方式账号？

---

## Current Position

Harper 真正有差异的地方，不是“设计师日常”，也不是泛泛的“女性成长”或“个人思考”。

差异来自一个真实交叉点：

> **我正在真实参与品牌从 0 到 1，同时又是视觉设计师，因此可以把设计、品牌、商业和职业成长放在同一个真实现场里讲。**

核心内部定位：

> **给正在从“执行者”走向“建设者”的年轻设计师和创意工作者，分享真实品牌建设中的设计判断、商业思考和职业成长。**

更长期、更简洁的一句话：

> **Harper documents how a designer learns to see, think and build.**
>
> 记录一个设计师如何学习看、学习判断、学习建立东西。

账号的长期母题不是“做设计”，而是：

> **How to become a builder, not just an executor.**  
> **怎么从一个执行者，慢慢成为一个有判断力的建设者。**

---

## Why This Position Matters

大量年轻设计师真正卡住的地方，不是不会做图，而是：

- 会执行，但不知道如何判断；
- 会完成需求，但不知道如何主动推动问题；
- 能看到“好看的设计”，但不知道为什么成立；
- 知道设计，却很少接触品牌、商业、产品和真实组织协作；
- 想往上走，但不知道“执行设计师”之后的能力到底是什么。

Harper 不需要站在“已经成功十年的 Creative Director”位置上教别人。

更真实的位置是：

> **我正在经历这一步，也比一些人早走了几步。我把正在验证、推翻和形成的判断公开出来。**

所以价值不是提供标准答案，而是让别人跟着一个真实职业轨迹，一起获得新的看法。

---

# The Value I Can Give

## 1. DESIGN — 帮别人看懂设计

不是教软件，也不是简单点评“好不好看”。

更重要的是理解设计决定：

- 为什么这个品牌看起来成立；
- 为什么某些视觉克制但有力量；
- 为什么一个包装、字体、构图或系统会产生特定感受；
- 一个优秀案例如何从问题、策略一路走到视觉；
- 为什么不能只收藏最后那张漂亮 Logo。

核心变化：

> **从看结果，走向看决定。**

这构成 Harper 的专业吸引力。

---

## 2. BUILD — 帮别人看懂真实工作与品牌建设

这是 Harper 最稀缺的一层，因为它来自正在发生的真实工作。

可以持续讨论：

- 设计师为什么不能只等需求；
- 什么是 Partner mindset；
- 如何从执行者变成项目推动者；
- 品牌从 0 到 1 时，设计之外还发生了什么；
- 如何和老板、销售、产品、供应链、设计师一起工作；
- 为什么设计师需要理解一点商业；
- 如何把真实公司和项目变成自己的训练场；
- 一个产品从想法到市场，中间有哪些并不“像设计”的决定。

这里不是展示“我今天工作很忙”。

而是从工作中抽出可以迁移的判断。

---

## 3. THINK — 帮别人建立判断力

这是未来最值得长期积累的一层。

Harper 经常做的事情其实是：

- 看到设计，追问它为什么成立；
- 看到品牌，追问商业上是否成立；
- 看到职业选择，追问它是否会成为长期资产；
- 读到一个观点，不只摘金句，而是判断自己是否认同；
- 意识到旧观点不够准确时，允许自己改变。

所以最终输出的不是一堆知识，而是：

> **一个人怎么慢慢形成自己的判断。**

这也是个人 IP 能够超越“设计博主”的地方。

---

# Content Architecture

未来可以用三个词快速判断内容，但它们不是三个赛道，而是同一母题的三个视角。

## DESIGN | 怎么看

审美、品牌案例、视觉、设计史、设计方法、设计决定。

重点不是“介绍这个案例”，而是：

> **这里有一个设计决定，我以前只觉得好看，现在终于看懂了一点它为什么成立。**

## BUILD | 怎么做

真实品牌建设、产品、项目、商业、协作、决策、推进过程。

重点不是工作流水账，而是：

> **真实建设过程中，什么问题改变了我的做法和判断？**

## THINK | 怎么判断

职业、野心、成长、选择、阅读、自我建立。

重点不是泛泛的人生感悟，而是：

> **一段真实经历，如何让我重新理解一件事？这对另一个人有什么可带走的角度？**

它们共同指向：

```text
SEE -> THINK -> BUILD
看见 -> 判断 -> 建立
```

# Personal Does Not Mean Private

“个人 IP”的个人，不等于必须大量自拍、展示吃饭、旅行、房间和私人关系。

真正重要的是：

> **观点有主语。**

不是：

> 设计师应该懂商业。

而是：

> 我以前会本能地把商业和设计的纯粹性放在两边。真正开始参与一个品牌之后，我才发现，我过去理解的“专业”可能太窄了。

个人感来自：

- 我经历了什么；
- 我原来怎么想；
- 什么让我改变；
- 我现在怎么看；
- 这个变化对别人意味着什么。

因此内容可以克制、理性、安静，不需要为了“真人感”强迫自己变成外向型博主。

---

# Expression Direction — Visual Essay

最适合 Harper 的形式不是纯口播，也不是纯 Vlog，而是：

> **围绕一个真正想说的主题，用声音讲述，再用画面去支撑。**

更准确地说：

> **声音负责思考，画面负责建立世界。**

画面不需要逐字解释旁白。

优先使用真实创作证据：

- 设计文件与废稿；
- Brief、打印稿、手写标记；
- 产品样品与包装测试；
- Illustrator / Figma / PDF 工作界面；
- 会议准备与真实工作现场；
- 正在看的案例、书和资料；
- 城市里真正引起注意的字体、包装、产品和视觉；
- 必要时少量使用电影、广告、档案影像等作为隐喻或文化共识。

这些不是为了“显得专业”，而是在自然证明：

> **这个人是真的在做东西。**

### Avoid

不要掉入可替代的“高级感 B-roll”：

```text
咖啡 -> MacBook -> 打字 -> 翻书 -> 建筑 -> 走路 -> 咖啡
```

Harper 的视觉世界应该建立在：

> **真实创作痕迹 + 克制的编辑感**

而不是靠生活环境必须很贵、很精致来支撑。

# The Most Important Content Rule

以后每一个选题发布前，只问一个最重要的问题：

> **观众看完以后，能不能带走一个新的判断？**

如果只是：

> Harper 今天想了很多。

不够。

如果变成：

> 我原来以为工作只是完成任务，但我现在开始重新思考，怎样利用真实公司和项目训练以后属于自己的能力。

成立。

如果只是：

> 这个品牌真好看。

不够。

如果变成：

> 我终于看懂，为什么这个品牌即使没有复杂视觉，仍然有很强的品牌感。

成立。

因此内容价值不是“给答案”，而是：

> **让别人看完以后，多一个看事情的角度。**

---

# Topic Filter

一个主题值得成为 Harper 的内容，最好至少满足其中三项：

- 我真的正在经历或研究它，而不是为了发内容硬想；
- 我的看法发生过变化；
- 里面存在真实矛盾、问题或张力；
- 它和设计、品牌、工作、成长的长期母题有关；
- 别人也可能面对类似问题；
- 有真实材料能够成为视觉证据；
- 一年后回看，它仍然属于我的职业轨迹；
- 观众可以带走一个新的判断。

---

# What This Account Is Not

- 不是“5 个设计师必看网站”式工具号；
- 不是 Pinterest / Brand New 的二次搬运；
- 不是只展示最终作品的作品墙；
- 不是泛泛的职场成长号；
- 不是把所有情绪都上升成人生哲理的自我感动；
- 不是用咖啡、MacBook、建筑空镜制造高级感的氛围号；
- 不是为了个人 IP 而强迫自己大量露脸和暴露私人生活。

工具、案例、生活、阅读都可以出现，但必须服务于同一条主线：

> **Harper 正在如何形成自己的判断，并逐渐成为一个 Builder。**

# First Content Experiments

目前不需要规划几十条。先通过少量真实内容验证表达方式。

### 01 — 我开始不想再用“打工人”的方式工作了

核心不是鼓吹努力或加班，而是：

> 工作最有价值的部分，不只是替公司完成多少，而是能不能借真实商业环境，把未来属于自己的能力练出来。

### 02 — 品牌设计不是从 Logo 开始的

核心不是教“品牌设计流程”，而是记录：

> 一个设计师如何从只看最终视觉，慢慢学会往前追问题、策略和决定。

### 03 — 我正在重新理解“野心”

核心不是励志，而是：

> 怎样让野心不只是焦虑，而变成长期行动和能力积累。

# Long-Term Assets

如果这个个人 IP 长期成立，真正积累的不只是粉丝，而是四种资产：

1. **Judgment — 判断档案**  
   能看到自己如何理解设计、品牌、商业和职业，以及这些理解如何改变。

2. **Evidence — 真实过程证据**  
   不只有 Portfolio 的最终稿，还有真实的 building process。

3. **Voice — 自己的表达方式**  
   内容不依赖博主模板，而逐渐形成 Harper 自己的语言和视觉气质。

4. **Trajectory — 职业轨迹**  
   让别人看到一个人不是突然“成为谁”，而是一步一步走过去的。

# Open Questions

这仍然是 Working Thesis，以下问题需要通过真实发布继续验证：

- DESIGN / BUILD / THINK 中，哪一种最容易形成最强的观众连接？
- 专业内容与更个人的职业思考应该保持什么比例？
- 不露脸或少露脸时，怎样仍然建立足够强的“真人感”？
- 如何在真实项目证据与商业保密之间建立边界？
- Visual Essay 的长度、节奏和平台形式如何适配小红书与抖音？
- Harper 的受众最终更集中于年轻设计师，还是更广泛的年轻创意工作者？

这些不需要现在强行回答。

应该通过持续发布和真实反馈来验证，而不是先在纸面上把“赛道”定义死。
