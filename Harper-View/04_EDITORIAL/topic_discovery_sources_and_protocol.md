# Harper View｜选题发现资源地图与研究协议

> 版本：v0.1｜整理日期：2026-10-21  
> 用途：每次启动**新的选题探索**时使用。它是可更新的资源与检验方法，不是固定选题库，也不要求每次穷尽全部网站。  
> 上位原则：[内容创作理念与 AI 协作原则](../01_VISION/content_creation_and_ai_collaboration.md)；具体表达规范：[editorial_method.md](editorial_method.md)。

## 0. 先说清楚我们在找什么

Harper View 不是纯时尚账号、设计师教学账号，也不是只讲品牌营销的账号。它从**审美、观看、设计判断、品牌意义与生活经验**切入，为非设计师也能理解的广泛观众提供真实的认知增量。

以前的错误路径：先找到论文 → 强行提炼观点 → 拼标题 → 最后寻找观众关联。这会产生「有研究、却没有人真正关心」的视频。

更合理的双线探索：

- **受众需求线（Demand）**：人们真实在搜索、困惑、争论、转发、比较什么？有没有反复出现但缺乏好解释的经验？
- **外部知识线（Knowledge）**：相关问题在认知心理学、社会心理学、审美心理学、传播学、消费者行为、社会学、人类学、哲学、视觉文化、设计史等领域，已经有哪些重要研究、争议或可核实发现？
- **交集（Opportunity）**：是否存在一个广泛可理解的问题，可以被可靠的新知识重新解释，同时能通过视觉叙事而非讲课来呈现？

「有论文」不等于「有好选题」；「搜索热」不等于「你的受众有需求」；「反常识」不等于真实。真正进入内容制作前，必须过三道门：**有人在意／确有知识增量／符合账号定位与视觉表达优势**。

## 1. 五种证据信号：不要互相替代

| 信号 | 能回答 | 不能证明 |
| --- | --- | --- |
| **搜索需求**（搜索建议、相关词、趋势） | 用户主动在寻找什么、某一问题何时被关注 | 搜索者为什么搜索；绝对人数；视频一定会传播 |
| **受众原话**（评论、社区提问、个人访谈） | 人们如何描述困惑、争议、情绪及选择 | 抽样评论代表大众；评论多就是重要痛点 |
| **传播反馈**（完播、收藏、分享、涨粉、对照视频） | 哪种表达可能引起注意、共鸣或传播 | 高播放完全由选题造成；有单条爆款就可复制 |
| **学术与一手证据**（论文、书籍、报告、档案） | 已有研究怎样解释机制、有何证据和边界 | 某个理论自动适用于中国所有群体；研究能预测平台流量 |
| **视觉／品牌案例**（设计方、作品、历史档案） | 具体决策与视觉差别如何让理论变得可见 | 单个案例能证明普遍因果规律 |

## 2. 资源地图：国内需求与传播

**优先级最高是自己账号的第一方数据**：抖音与小红书后台的视频指标、评论、收藏分享、净涨粉等，尤其比较「高播放但不涨粉」和「播放不高但大量收藏／关注」的内容。平台后台须登录；AI 不能默认直接读取。可以由 Harper 提供自己合法导出的数据或匿名化文本供分析。

| 资源及直达入口 | 重点观察 | 访问与证据边界 |
| --- | --- | --- |
| [小红书创作服务平台](https://creator.xiaohongshu.com/) | 自有内容数据、受众反馈、创作工具；再结合站内搜索联想及同题评论 | 官方入口，但部分功能和后台数据需登录；不假设存在对 AI 开放的评论接口 |
| 抖音 App 内「创作者中心」与自有视频数据 | 播放、完播、评论、分享、涨粉及问题原话 | 需账号操作或导出；评论与用户隐私需匿名化 |
| [抖音指数（原巨量算数）](https://trendinsight.oceanengine.com/) | 主题关注变化、相关内容及可见的人群/趋势线索 | 官方站点多为 JavaScript 动态页面；受登录、地区和页面权限限制；不能声称已自动获取实时数据 |
| [百度指数](https://index.baidu.com/) · [官方功能说明](https://index.baidu.com/Helper) | 搜索趋势、需求图谱、来源词／去向词、人群结构 | 体现**百度搜索行为**而非全网绝对人数；部分词与专业功能收费／需登录 |
| [新榜](https://www.newrank.cn/)（新红、新抖等） | 跨账号内容榜单、低粉高互动内容、话题表现 | 第三方数据平台；不同栏目与深度分析有权限/付费门槛，算法及覆盖范围以其披露为准 |
| [千瓜行业报告索引（果集）](https://www.guoji.pro/Report) | 小红书相关行业热词、需求与消费变化、研究线索 | 行业研究资料，有营销视角与采样边界；报告列表公开不代表全文和底层数据开放 |
| 小红书／抖音 App 内人工检索 | 搜索建议、同题高互动作品、评论区中的真实问句、反对意见 | 搜索结果会因账号和推荐系统变化；记录检索词、时间、可见证据，而非把截图当全体用户调查 |

**中文搜索方法**：对同一候选母题，不只搜「审美」「风格」「高级感」，还搜口语化的第一人称困惑（如「看了很多还是不会选」「不敢相信自己的审美」），以及相反立场、质疑、失望体验；具体词语来自真实检索，不可由 AI 伪造为已出现的用户原话。

| 资源 | 重点观察 | 访问与适用边界 |
| --- | --- | --- |

| [TikTok Creative Center — Trends](https://ads.tiktok.com/business/creativecenter/hashtag/find) | 海外内容趋势与表现形式 | TikTok 不等于中国抖音；标签热度偏「正在被生产／传播」，不是所有人的深层需求 |
| [TikTok Creative Center — Top Ads](https://ads.tiktok.com/business/creativecenter/inspiration/topads/pc/en) · [官方说明](https://ads.tiktok.com/resources/help/article/top-ads) | 已授权公开的高表现广告、镜头节奏及分秒表现 | 只是经过筛选及授权的广告样本；不是全平台自然流量内容；完整分析可能登录受限 |
| [Reddit](https://www.reddit.com/)（如 r/femalefashionadvice、r/Design） | 更长的第一人称困惑、争议、反面意见与经验叙述 | 匿名论坛的质性线索；文化背景和自我选择偏差明显，不能作为中国观众需求的统计证明 |
| [Pew Research Center](https://www.pewresearch.org/) | 可查抽样方法的社会态度／媒介使用调查 | 先看国家、人群、年份、调查方法；美国样本不能直接外推中国 |

**跨文化使用准则**：先通过海外讨论发现陌生问题与概念，再返回中文搜索和自己账号的反馈中验证本地关联。不可说「Reddit 用户在讨论，因此中国用户也普遍这样」。

## 4. 资源地图：心理学、跨学科知识和原始文献

以下是**每个新主题的常规知识入口**，不是仅当视频叫“心理学”才使用。

| 资源 | 用途 | 应留意 |
| --- | --- | --- |
| [Semantic Scholar](https://www.semanticscholar.org/) · [官方产品介绍](https://webflow.semanticscholar.org/product) | 搜论文、沿引用关系扩展、跨领域发现研究 | 有些只提供摘要或索引；AI 摘要不是原文的替代品；自动访问可能被限制 |
| [OpenAlex](https://openalex.org/) · [Works 帮助](https://help.openalex.org/data/works/) | 论文、作者、引用、研究主题、OA 线索 | 元数据或开放全文索引 != 每篇论文全文免费或经证实 |
| [Crossref](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | DOI、发表年份、刊名、作者、后续更正与书目信息核对 | **主要是元数据索引**，不等于论文内容或可信度评估 |
| [APA PsycArticles](https://www.apa.org/pubs/databases/psycarticles) | 心理学同行评审期刊，尤其认知、社会、实验心理学 | 全文通常需要个人／机构订阅；不要宣称全部免费 |
| [PsyArXiv](https://osf.io/preprints/psyarxiv) · [OSF 说明](https://help.osf.io/article/376-preprints-home-page) | 获取心理学预印本与初步研究方向 | **预印本未必经过期刊同行评审**；遇到更新须检查正式发表版本 |
| [《心理科学进展》](https://journal.psych.ac.cn/xlkxjz/) · [中国科学院介绍](https://www.psych.cas.cn/journal/xlkxjz/) | 中文心理学综述、前沿与元分析；帮助找到中文研究概念 | 综述不是一手实验；引用某个结论时再回到被综述的关键原始论文 |
| [万方数据期刊检索](https://c.g.wanfangdata.com.cn/periodical) | 中文心理学、传播学、设计学、社会学文献的题名和摘要入口 | 部分全文需要账号/机构权限 |
| [Google Scholar](https://scholar.google.com/) | 补充文献检索与引文线索 | 要核查实际出版类型、版本和出版社；访问可能受地区限制 |

**跨学科检索范畴（不规定最后内容必须属于这些学科）：** 审美感知与认知流畅性（aesthetic perception / processing fluency）、社会比较（social comparison）、视觉注意与判断（visual attention / aesthetic judgment）、身份与自我呈现（identity / self-presentation）、社会信号与地位（signaling / status inference）、消费文化（consumer culture）、具身体验（embodied experience）、文化资本与品味（cultural capital / taste）、媒介和传播（media psychology / sharing behavior）、设计史与美学哲学。中英文并搜，同义词与反向论据并搜。

**查论文的顺序**：先确认问题和学科 → 找高质量综述／系统综述以确定争议和关键词 → 检查最关键原始研究的样本、方法、核心数据、效应与边界 → 搜索后续复制研究、反例与批评 → 记录准确 DOI 和公开全文状态。

传播心理学的一个起点：[Berger & Milkman (2012), *What Makes Online Content Viral?*](https://doi.org/10.1509/jmr.10.0353)。研究了 NYT 新闻分享与情绪唤醒的关联；**不能**当成 2026 年抖音算法或「制造焦虑就会爆」的公式。

## 5. 资源地图：真实设计／品牌／视觉文化案例

| 资源 | 用途 | 类型与边界 |
| --- | --- | --- |
| [Pentagram — Work](https://www.pentagram.com/work) | 查看创作者如何叙述设计目标、策略与具体实现 | **设计方一手叙述**；是项目决策材料，不自动证明消费者效果 |
| [Brand New — Archives](https://www.underconsideration.com/brandnew/archives/complete) | 品牌识别与重设计的对照、专业评论和争议 | **第三方评论**；不是品牌方原始文件；一些内容需订阅 |
| [It's Nice That](https://www.itsnicethat.com/) | 创意文化、摄影、设计、视觉叙事及创作人访谈 | 编辑策展和文化评论；提及数据或创作者意图要追到原始来源 |
| 品牌官网、设计机构案例、历史档案、公开年报、展览目录 | 真实设计选择／时间线／品牌表达；为研究建立可见的案例 | 广告文案/公关表述是当事方主张，不等于独立的市场或心理实验结果 |

案例研究至少分为：**看得见的作品事实、设计方说明、研究者解释、我们自己的判断、商业表现**；这五项不可写成一个因果结论。

## 6. 每次启动选题探索的实际工作流

### A. 双线并行，先不想标题

1. **受众需求线**：参考「自己数据 → 中文平台检索 → 全球讨论作对照」，收集一批**有出处**的真实问句、相互矛盾的想法或反复困惑，分清搜索、评论与真实观看行为。
2. **外部知识线**：AI 不以 Harper 已提出的观点为边界，独立从心理学、社会学、文化研究、设计学等领域找陌生而可靠的发现，并说明为什么相关。
3. **发现交叉点**：不要先选最吸睛论文；找「用户在意且已有知识能提供新解释」的真实问题，必要时从陌生知识反向提出一个尚未被搜索表明的潜在问题，并明确这是待验证假设。

### B. 小范围深研，而不是堆更多标题

4. 对初选方向，至少核对一项一手或学术依据，追一个反例／竞争性解释；记录这究竟是**事实、理论解释、模型结果，还是我们的推论**。
5. 做传播评估：**普通非设计师会不会关心？** 能否在短片里形成具体冲突、可信的认知转折与画面证据？与过去内容重复吗？是否容易走向标题党、陈词滥调或单纯时尚穿搭？
6. 只交付少量可深入的「研究型内容机会卡」。每张卡必须包含：受众真实问题及原文出处｜证据覆盖面／不确定性｜最重要的研究发现与 DOI／原始链接｜反例与边界｜为什么不是常识｜具体视觉叙事可能性｜为什么属于 Harper View｜是否应淘汰。

### C. 先打动创作者，再写脚本

7. Harper 与 AI 先讨论**研究发现是否真的改变了理解**。若 Harper 自己读完没有新的理解或视觉体验，则标记「资料值得留存／选题暂不成立」，不要为赶产量硬写。
8. 通过后才出完整内容策划（观众问题 → 研究性转折 → 视觉证据 → 独立判断），然后才写约三分钟的旁白；以画面能够展示什么为叙事结构的一部分。
9. **广告商品后置**：独立内容先成立，商品选取和植入是后续编辑决策；若商品与论证不符，不能反过来修改事实以服务带货。
10. 交给 Codex 的是**确认过的研究摘要、来源定位、分镜需求、素材许可与制作规范**，不让剪辑阶段重新编造研究。发布后复盘「观看／分享／收藏／涨粉」与内容机制，保存有效教训。

## 7. 最小记录格式：便于新对话继续工作

每次探索留下一页 Markdown（或供 Codex 分析的表格），而不是只留聊天记录：

- 检索日期、平台／国家／搜索词／筛选范围与能否实际访问；
- 原始需求信号（评论做匿名化处理）、公开来源链接、是否只是平台算法排序；
- 学术来源（作者／年份／标题／期刊／DOI／研究类型／样本／核心发现／局限／反面证据）；
- 是否有足够的**具体观众问题**和**真实认知增量**；
- 与 Harper View 受众、表达定位、视觉叙事的连接方式；
- 当前结论：**候选／继续查证／暂不做／入制作／已发布**，附理由；
- 下次接续时最重要的 1–3 个未解决问题。

**隐私和版权**：公开 GitHub 不上传粉丝 ID、微信、私信、未获授权的评论全文、平台后台截图或私有账号数据；如需记录评论，只存匿名化归纳与可公开引用的短摘录和合法链接。不要公开上传付费书籍、论文全文或素材库；存书目、DOI、研究笔记及必要短引。遵守平台使用条款，不以绕过登录或批量违规抓取作为工作流前提。

## 8. 新对话启动指令（可直接复制）

> 请以 `Harper-View/01_VISION/content_creation_and_ai_collaboration.md` 与本文件为研究准则，开启一次新的选题探索。不要先给我 20 个标题，也不要重复我已有的审美观点。请并行检索（A）中文受众需求与平台反馈，必要时借助海外趋势和社区补充陌生问题；（B）心理学、社会学、传播学、审美与视觉文化的论文、综述和原始案例。明确标注各来源实际访问状态、样本/地区、可信边界和未经证实的推测。从交集里提出少量「有人关心且能改变理解」的研究型内容机会，保留反例和反对意见。优先选择非设计师也能理解、视觉表现强、能反映 Harper View 独立判断的方向。**在我们认可研究核心之前，不写旁白，不选广告商品。**

## 9. 后续维护

- 本目录是**资源与方法导航**，不是未经审核的数据抓取说明。链接有效性、访问权限与平台功能会改变，应按需复查。
- 每次真正用到来源，再在具体主题档案里记录「访问日期、所见内容、证据和结论」。不将本资源导航误当成已获取的数据。
- 如果长时间出现「找到论文但选题没感觉」，先回到**真实受众困惑**，而不是继续为同一研究改标题。
