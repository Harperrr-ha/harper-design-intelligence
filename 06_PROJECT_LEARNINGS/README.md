# 06_PROJECT_LEARNINGS

Transferable learning from real work.

This is not project management.

Do not store:

- project progress
- To Do items
- deadlines
- meeting minute streams
- file versions
- task status

Project Learning keeps what should survive after the project ends.

## Agent Questions

- What happened?
- Why did it matter?
- What did Harper originally think?
- What did Harper realize?
- Is this project-specific or transferable?
- Which Insight does it support?
- Does it challenge an existing belief?
- Could it eventually change a Principle or Method?

Use `templates/project-learning-template.md` for new project learnings.
