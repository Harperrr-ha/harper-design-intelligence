# 06_PROJECT_LEARNINGS

Transferable learning from real work.

This is not project management. Do not store tasks, timelines, or status reports here.

Record what the project taught Harper that can transfer into future design judgment.

Each Project Learning should include:

- Origin Project
- What Happened
- What I Learned
- Why It Matters
- Transferable Insight
- Related Principle / Method

Use `templates/project-learning-template.md` for new project learnings.
