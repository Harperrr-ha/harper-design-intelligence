# 02_INSIGHTS

One file equals one independent judgment.

This folder is not organized by source or project. It is organized by thought.

Do not create a new Insight until existing Insights have been checked for overlap.

## Agent Questions

- Can the thought be stated clearly?
- Is it new, or existing knowledge with new evidence?
- What source or experience produced it?
- What supports it?
- What challenges it?
- What is Harper's current conclusion?
- What remains open?
- Does it connect to a Working Thesis?
- Is it a Principle Candidate, or not mature enough?

Use `templates/insight-template.md` only when a real independent thought should be preserved.
